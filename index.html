How we plan internal links for clients

Every link should push toward a money page.

Group like pages by relevance. Pick the page in each group that makes money. Then point the rest of the group at it, using anchors that describe what it's about.

Pages link wherever someone happened to add a link. Nothing points anywhere on purpose.

Anchor text

Anchors should model the money page's topic

The anchor is the clickable text. It tells search engines and readers what the linked page is about, so it should describe the money page, in slightly different words each time.

The checklist

Four rules for every client

Group like pages by relevance

Sort by topic first. A page belongs in a group if it's about the same thing that group's searcher wants.

Choose one money page per group

The page that turns visitors into leads or sales. Usually a service or product page.

Point support pages at it

Blog posts, guides, cost pages, and project pages in the group each link to the money page.

Target the anchors, then vary them

Every anchor describes the money page's topic. No two are identical, and none say "click here."
